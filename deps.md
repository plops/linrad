# Linrad External Dependencies & GitHub Organizations

This file lists the external dependencies, drivers, libraries, and tools used by Linrad along with their GitHub organization/repository identifiers for DeepWiki queries.

| Dependency / Library | Description | GitHub Organization / Repository | DeepWiki Query Repo Target |
